# Voices of India

Build a polished, premium, responsive React/Next.js web application called LOKVAANI.

BRAND

LOKVAANI

“Preserving voices. Connecting cultures.”

LOKVAANI is an AI-powered living digital archive for India's oral cultural heritage.

The core concept is:

Preserve → Understand → Connect → Discover

The website is a Smart India Hackathon prototype, so use realistic mock data and simulate AI functionality on the frontend. Do NOT build a real backend.

PRIMARY GOAL

Use the available build budget efficiently.

Prioritize:

Exceptional visual design

Fully responsive UI

Homepage

Explore/search experience

Story detail page

Contribution/AI processing demo

Working navigation between these pages

Do NOT spend effort on authentication, databases, APIs, admin panels or real AI models.
